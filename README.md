# ⏱️ Metronom

Ein Metronom für den Musikunterricht – läuft direkt im Browser, auf Handy, Tablet und Whiteboard.

**Zur Seite:** https://greenboy87.github.io/metronom/

## Funktionen

- **Tempo am Drehrad:** am äußeren Ring drehen, in der Mitte stehen BPM und Tempobezeichnung (z. B. *Andante – gehend*)
- **Tempo tippen:** gleichmäßig auf das Tipp-Feld tippen, das Tempo wird übernommen
- **Taktart:** Vorlagen (2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 12/8) oder frei 1–12 Schläge über 2, 4 oder 8
- **Betonung je Schlag:** jeden Schlag auf *hoch*, *tief* oder *aus* stellen
- **Unterteilung:** Viertel, Achtel, Triolen, Sechzehntel – mit mitlaufender Zählhilfe („1 + 2 +“)
- **Tempo-Trainer:** alle N Takte automatisch schneller (oder langsamer) bis zum Zieltempo
- **Stille Takte:** das Metronom setzt aus – hält man das Tempo allein?
- **Klänge:** Klick, Holzblock, Piepton, Lautstärkeregler, optionales Blinken im Takt
- **Übungszeit** und gespeicherte Einstellungen auf dem Gerät

Tastatur: Leertaste = Start/Stopp, T = tippen, Pfeiltasten = Tempo ±1 (mit Umschalt ±5).
